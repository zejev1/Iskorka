# SPCK: Искорка 0.1.0-stage1

Импортируйте ZIP как **отдельный проект**, не поверх Ainkrad. В корне должны находиться `index.html`, `package.json`, `src/`, `assets/` и скрытая `.git/`; дополнительной папки внутри проекта нет.

В архиве уже есть локальный коммит. Git remote: `https://github.com/zejev1/Iskorka.git`. Ветка: `bootstrap/iskorka-stage1-spck-20260918`. Это отдельная ветка доставки, чтобы не затереть параллельные изменения `bootstrap/iskorka-human-lab`.

Перед Push проверьте remote и ветку. Новый коммит вручную делать не требуется, если после импорта файлы не редактировались. При ошибке авторизации используется ваше обычное подключение GitHub в SPCK; в архиве токенов нет. **Force Push не использовать.** Если SPCK удалил `.git` при импорте или показывает другой адрес/ветку — не нажимайте Push и не создавайте несвязанную историю поверх существующей ветки.

Для предпросмотра запускайте корневой `index.html` через сервер предпросмотра SPCK. Исходники уже собраны в `assets/`; Node на телефоне для этого не нужен. Не открывайте HTML как обычный `file://` файл — модульному Worker нужен веб-origin. Совместимость конкретного предпросмотра SPCK пока не проверена на устройстве.

Для пересборки на Node 22+: `npm ci`, `npm run verify`. Результат для размещения — `dist/`; для SPCK те же assets копируются в корень. Сборка не разворачивается автоматически в Ainkrad и не меняет его сохранения. Сохранения завязаны на веб-origin: мир в предпросмотре и на отдельном сайте будет храниться раздельно.
