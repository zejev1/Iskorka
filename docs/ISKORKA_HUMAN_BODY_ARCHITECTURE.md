# Искра: человеческое тело и связь тело ↔ разум

Статус: архитектурная цель, до начала реализации.
Ветка проектирования: `design/body-human-physiology-v1`.

## 1. Неподвижные правила

1. Существующий мозг Искр пока не заменяем.
2. Существующую систему сна не переписываем. Сон уже является телесным ограничением; новый слой только подключается к нему.
3. Тело не принимает решения вместо личности. Тело создаёт ощущения, ограничения и импульсы; разум интерпретирует их и выбирает действие.
4. Сексуальная физиология и сексуальные взаимодействия моделируются только для взрослых Искр (18+).
5. Никаких "магических" прямых эффектов вроде `sex => joy +0.5` или `fear => tremor=true`. Причинность проходит через тело.
6. Тело должно оставаться дешёвым по CPU/RAM. Мы берём идеи из внешних проектов, но пишем собственную компактную реализацию.
7. При ускорении мира тело не должно считать миллионы микрошагов. Используем события, редкие физиологические обновления и аналитическое изменение за интервал.

## 2. Базовая причинная схема

Внешний мир / действие / событие
→ органы чувств и телесные системы
→ внутреннее физиологическое состояние
→ телесные ощущения (interoception)
→ мозг / эмоции / память / решение
→ действие
→ новое изменение тела.

Обратное направление также обязательно:
эмоция / мысль
→ вегетативная + эндокринная реакция
→ сердцебиение, дыхание, мышцы, пот, слёзы, дрожь, сексуальное возбуждение и т.д.
→ новые телесные ощущения
→ обратное влияние на эмоцию.

## 3. Системы организма

Сохраняем существующие:
- skin
- musculoskeletal
- circulatory
- respiratory
- digestive
- nervous
- immune

Добавляем:
- endocrine — гормональная/стрессовая регуляция;
- renal — вода, соли, мочеобразование;
- reproductive — взрослая половая и репродуктивная физиология;
- sensory — зрение, слух, запах, вкус, осязание, температура, боль, проприоцепция, равновесие.

Органы не обязаны существовать как отдельные тяжёлые объекты. Для обычной Искры достаточно компактного состояния систем + редких локальных состояний (рана, болезнь, беременность и т.п.).

- холодовой стресс;
- тепловой стресс;
- физическое истощение;
- восстановление;

- позыв к мочеиспусканию;

Тело должно влиять на:
- ходьбу;
- бег;
- ускорение;
- подъём/перенос веса;
- работу;
- охоту;
- бой;
- плавание/нахождение в воде, если будет поддержано физикой;
- равновесие;
- координацию;
- мелкую моторику;
- устойчивость;
- скорость реакции;
- выносливость;
- мышечную усталость;
- одышку;
- восстановление после нагрузки;
- хромоту;
- ограничение движения из-за боли/раны/перелома;
- потерю сознания/коллапс при тяжёлом состоянии.

Бег:
нагрузка → рост дыхательной/сердечной нагрузки → мышечная усталость → одышка → падение доступной скорости → восстановление после остановки.

## 7. Боль, раны, травмы

Существующие раны расширяются телесными последствиями:
- локальная боль;
- острая/затухающая боль;
- кровотечение;
- воспаление;
- загрязнение;
- риск инфекции;
- отёк;
- нарушение движения;
- слабость от кровопотери;
- шок при тяжёлой травме;
- потеря сознания при критическом состоянии;
- заживление;
- остаточная боль;
- рубец как лёгкая долговременная запись, если будет полезен.

Рана:
повреждение ткани → боль/кровотечение/ограничение → телесный сигнал → страх/стресс/осторожность мозга.

## 8. Болезни и иммунная реакция

Тело должно уметь выражать болезнь через:
- слабость;
- жар;
- озноб;
- воспаление;
- кашель;
- чихание;
- заложенность/дыхательный дискомфорт;
- тошноту;
- рвоту;
- диарею;
- потерю аппетита;
- обезвоживание;
- мышечную слабость;
- сонливость;
- боль;
- ухудшение восстановления;
- временное снижение подвижности;
- заразность, когда болезнь это предполагает.

## 9. Терморегуляция

Холод:
низкая температура среды + защита/одежда/укрытие
→ холодовой стресс
→ дрожь + сужение активности + дискомфорт
→ падение ловкости/скорости при тяжёлом состоянии
→ мозг получает "холодно".

Жара:
тепло + физическая нагрузка
→ потоотделение + жажда + слабость
→ при продолжении обезвоживание/перегрев
→ мозг получает "жарко/нужно пить/нужно остановиться".

Дополнительно:
- комфортная температура;
- согревание;
- охлаждение;
- тепло от огня/дома/другого человека;
- влажность и ветер как модификаторы, если дёшево.

## 10. Вегетативная физиология

Компактный `BodyAffect / AutonomicState`:
- autonomicArousal;
- heartRateLoad;
- breathingLoad;
- muscleTension;
- sweating;
- tremor;
- blushing;
- pupilArousal;
- dryMouth;
- goosebumps;
- tears;
- startle;
- physicalPleasure;
- physicalDiscomfort;
- nausea;
- dizziness;
- postStressRelaxation.

Это не "эмоции". Это физическая реакция тела.

## 11. Мост эмоция → тело

Страх:
fear → autonomicArousal → учащённое дыхание/сердцебиение + напряжение + пот + дрожь + startle.
При очень сильном страхе возможны freeze/слабость/сужение поведения, но решение всё равно не принимает тело.

Горе:
grief → тяжесть/упадок энергии + слёзы + изменение дыхания + снижение физической активности.

Радость:
joy → расслабление части мышечного напряжения + улыбка/смех как выражение + положительный телесный фон.

Надежда:
hope → снижение части стрессовой нагрузки, если нет сильной физической угрозы.

Благоговение/awe:
awe → goosebumps + изменение дыхания + краткий рост autonomicArousal.

Злость/раздражение (если будет выделено отдельно или выводиться из stress/conflict):
→ мышечное напряжение + autonomicArousal + жар/сжатие челюсти/резкость движений.

Тревога:
→ пульс + дыхание + сухость во рту + дрожь + тошнота у части Искр.

Смущение:
→ blushing + взгляд/поза как выражение, если личность так реагирует.

Отвращение:
→ nausea + отстранение от источника.

Облегчение:
→ быстрое снижение autonomicArousal + расслабление + глубокий выдох.

## 12. Мост тело → эмоция

- боль → повышает salience угрозы, страх/стресс/раздражительность;
- голод → повышает приоритет еды, при длительном голоде ухудшает настроение/концентрацию;
- жажда → повышает приоритет воды;
- одышка → усиливает ощущение угрозы/необходимость остановиться;
- высокая температура/озноб → ощущение болезни;
- мышечная усталость → снижает желание тяжёлой активности;
- приятное прикосновение → физическое удовольствие, затем мозг оценивает контекст;
- неприятное прикосновение → дискомфорт, защитная реакция;
- безопасность + тепло + знакомый человек → телесное расслабление, но не автоматическая "любовь";
- сексуальное возбуждение → сигнал мозгу, но не команда к действию;
- сильное удовольствие → положительная телесная обратная связь;
- тошнота → отвращение/отказ от еды или источника;
- головокружение → осторожность;
- телесная слабость → потребность в отдыхе.

## 13. Слёзы, плач, смех, улыбка, внешнее выражение

Слёзы принадлежат телу. Причины:
- grief;
- страх;
- боль;
- сильная радость;
- физическое раздражение глаз.

Отдельно:
- tearDrive — физиологический позыв;
- tears — реальная выраженность;
- suppression — попытка личности сдержать выражение.

Мозг может пытаться сдержать плач; это не обязано мгновенно убрать сам физиологический позыв.

Смех/улыбка:
- положительный эмоциональный импульс;
- социальный контекст;
- телесная возможность;
- личностная склонность выражать эмоцию.

## 14. Прикосновения

Прикосновение не равно "приятно".

Результат зависит от:
- типа контакта;
- силы;
- длительности;
- боли/раны;
- температуры;
- доверия;
- affinity;
- текущего страха/стресса;
- добровольности;
- личных особенностей;
- социального контекста.

Выход:
- pleasant;
- neutral;
- unpleasant;
- painful;
- comforting;
- threatening.

## 15. Взрослая сексуальная физиология

Строго разделяем:
- желание/намерение мозга;
- физическое сексуальное возбуждение тела;
- добровольное решение;
- физическое удовольствие;
- эмоциональную интерпретацию;
- желание ребёнка;
- репродукцию.

`physicalIntimacyInclination` не заменяет `sexualArousal`.

Состояния тела:
- sexualArousal;
- genitalResponse (обобщённый показатель, без необходимости моделировать анатомию покадрово);
- physicalPleasure;
- climax/разрядка как редкое событие, если условия достигнуты;
- sexualSatisfaction;
- postPleasureRelaxation;
- refractory/recovery state там, где применимо;
- temporarySleepiness/relaxation;
- pain/discomfort must reduce/stop positive response.

Причинность:
взаимное взрослое решение
→ физическое взаимодействие
→ телесная стимуляция
→ physicalPleasure
→ nervous/endocrine reward signal
→ мозг формирует эмоцию и память.

Удовольствие зависит от:
- возбуждения;
- комфорта;
- здоровья;
- энергии;
- отсутствия боли;
- чувства безопасности;
- доверия/affinity;
- текущего страха/stress;
- контекста и индивидуальной чувствительности.

Нельзя:
`sex => love`
`sex => trust`
`sex => joy`

Хороший опыт создаёт положительную память/валентность, после чего отношения могут измениться через обычную систему личности.

## 16. Репродуктивная физиология взрослых

Постепенно перенести в тело:
- возрастную фертильность;
- индивидуальную фертильность;
- репродуктивное здоровье;
- цикл фертильности в дешёвой агрегированной форме;
- зачатие как физическое последствие отдельного взрослого решения;
- беременность как телесное состояние;
- изменение энергии/нагрузки при беременности;
- роды;
- восстановление после родов;
- лактацию, если дети действительно будут пользоваться этим как физической потребностью;
- репродуктивное старение.

Репродукция никогда не должна быть синонимом секса.

## 18. Пищеварение и питание

- hunger;
- thirst;
- satiety;
- digestion load;
- nausea;
- vomiting;
- nutrient/energy deficit в упрощённой форме;
- malnutrition;
- dehydration;
- еда и вода реально меняют состояние тела;

Не создаём детальный химический желудок для каждой Искры.

## 19. Дешёвая архитектура

### Храним только состояние, которое имеет память
Пример:
- hydration;
- energyReserve;
- coreTemperature;
- fatigue;
- pain;
- sexualArousal;
- autonomicArousal.

### Производные значения не храним без необходимости
Например:
`breathlessness = f(respiratoryLoad, exertion, illness)`.

### Событийные импульсы
Удар, испуг, прикосновение, секс, еда, питьё, травма, болезнь:
→ один импульс в тело
→ затем состояние затухает математически.

### Разные частоты
- движение: уже существующий физический шаг;
- быстрые реакции тела: только при активном событии;
- гомеостаз: редкий шаг;
- болезнь/раны: ещё реже;
- долговременные изменения: по часам/дням мира.

### Аналитический catch-up
При большом интервале:
не 100 000 маленьких тиков,
а `state(t+dt) = decay/approach(state, target, dt)`.

### Спящие/далёкие Искры
Сводим физиологию к редкому агрегированному обновлению. Никакого рендера и частых телесных тиков вне необходимости.

### Память
Не хранить бесконечную телеметрию тела.
Хранить только:
- текущее состояние;
- активные раны/болезни;
- несколько значимых телесных событий как обычные воспоминания;
- долговременные изменения, если они влияют на жизнь.

## 20. Минимальный первый этап реализации

Body Homeostasis + Emotion Bridge:
1. hydration/thirst;
2. hunger/satiety;
3. temperature/cold/heat;
4. exertion/breathlessness/fatigue;
5. pain/body discomfort;
6. autonomicArousal;
7. muscleTension;
8. sweating;
9. tremor;
10. tears;
11. physicalPleasure;
12. sexualArousal — только взрослые;
13. postPleasureRelaxation;
14. body → mind signals;
15. mind emotions → body impulses;
16. подключение к существующему сну без его переписывания.

После этого остальные действия мира должны использовать один общий телесный слой, а не собственные независимые переменные.

## 21. Критерий качества

Искра считается телесной, когда наблюдаемое поведение можно объяснить цепочкой причин:

"что произошло с телом"
→ "что тело почувствовало"
→ "что разум из этого понял/почувствовал"
→ "что личность решила сделать".

Если действие возникает из скрытой магической прибавки к эмоции без физической причины, архитектура нарушена.

## 23. Как получить сотни функций без сотен дорогих симуляторов

Основной принцип: функция поведения не равна хранимой переменной.

Пример: одышка не обязана храниться. Её можно получить как
`f(exertionDebt, respiratoryHealth, oxygenDebt, fever, fearArousal)`.

Пример: дрожь может быть максимумом из дешёвых причин:
`max(coldStress, fearArousal * sensitivity, feverChill)`.

Пример: плач:
`tearDrive = f(grief, pain, fear, joyPeak, eyeIrritation)`,
а фактическое выражение дополнительно зависит от suppression личности.

Целевой бюджет обычной взрослой Искры:
- примерно 24–40 постоянно хранимых числовых физиологических значений;
- существующие 7–11 интегральных показателей здоровья систем;
- редкие sparse-объекты только для ран, болезней, беременности и других реально активных состояний;
- никакого отдельного объекта для сердца, лёгких, почек и каждой железы;
- никакой истории пульса/дыхания/температуры по тикам;
- производные ощущения рассчитываются только когда нужны решению, UI, событию или обновлению тела.

Так одна Искра может иметь широкий человеческий набор реакций без медицинского симулятора, работающего каждую секунду.
