# Искорка 0.1.0 — физический запуск

Донор: `zejev1/ainkrad-v0.3`, `0563af1dc1fea7d2abe76eb17501ef574078b4d2` (слитый F2, PR №8). Владелец подтвердил завершение 18.09.2026.

В рабочей ветке `bootstrap/iskorka-human-lab`: настоящий физический движок F2, отдельный runtime/worker без Cardinal, человеческий профиль, «Основание» на координатах первого поселения донора, 10 взрослых без готовых пар, одна библиотека. Другие поселения, расы, монстры и подземелья не создаются профилем. Обычная экология, погода, движение, ресурсы, хозяйство, чтение и физическая навигация сохранены. База IndexedDB, каналы вкладок и настройки отделены от Ainkrad.

Новый мозг, новое тело и язык из Конституции ещё НЕ реализованы: это исходная физическая основа, а не завершённая новая модель Искры. Дальнейшее развитие не подменять расширением старых сценариев. Cardinal удалён из исходников; общий движок сохраняет отключённые в профиле функции донора для изолированных регрессий физики.

Проверки воспроизводимы через `npm ci && npm run check && npm run build`, `node --test tools/bootstrap-profile.test.mjs`, `node tools/check-bootstrap-profile.mjs --require-donor`. Браузерные проверки: `tools/browser-smoke.py` после production build и запуска Vite preview. Результаты CI относятся к конкретному SHA, не к названию ветки. Удалённые проверки Cardinal перечислены в `tests/donor-scope.json` и не засчитываются как прошедшие.

Исходный Ainkrad/Cardinal и Vercel не изменяются. Автоматического слияния в main нет.
