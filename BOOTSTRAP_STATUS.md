# Первый физический запуск Iskorka 0.1.0

Донор: `zejev1/ainkrad-v0.3@0563af1dc1fea7d2abe76eb17501ef574078b4d2`.
Финальный F2 `f69d87b0ba4c3978c44faf8bc84acc555b588b85` имеет то же дерево `e3dcd421d6c0204fc61f92f970b00e07c6cf533b`; владелец подтвердил готовность 18.09.2026. Исходный Ainkrad и его Vercel не изменялись.

Реализованы настоящий импортированный физический движок, профиль десяти взрослых людей, «Основание», человеческая библиотека, обычные животные, отдельные UI/Worker/IndexedDB. Cardinal не создаётся и не импортируется исполняемыми графами. Другие расы, дополнительные начальные поселения, Genesis, монстры и подземелья не создаются. Физические перемещение, погода, чтение, ремесло, стройка, охота, лодки/рыбалка, ресурсы и исходная человеческая экономика сохранены.

Координаты не перенесены к центру: используется тот же конечный алгоритм размещения первого города F2. Сравнение площади, полей, мастерской, сада, окраины и десяти домов на трёх seeds проверяет точное совпадение.

## Проверки

- `npm run test:profile` — отдельные проверки неизменённых правил/полного handoff; не физический baseline.
- `npm run test:iskorka` — реальные человеческий мир, стройка, чтение, судостроение/навигация/рыбалка, 12 лет продолжения, IndexedDB и одинаковое будущее после reload.
- `npm test` — также все прежние регрессии донора. Не относящиеся к Iskorka проверки Cardinal/рас не удалены и не выдаются за включённые системы Iskorka.
- `npm run typecheck`, `npm run build` — оба графа сборки должны быть без Cardinal.
- `npm run test:browser` — production Worker/IndexedDB, desktop/mobile, пауза, реальное движение, save/reload, межвкладочная блокировка и reset. Требует отдельно установленного Playwright/Chromium; CI выполняет установку.

Текущий исходник не следует считать проверенным только по этому файлу: фактические результаты и снимки находятся в CI для точного commit SHA. Автоматического merge в main и изменения исходного Vercel нет.

## Границы первого этапа

Новые конечный мозг, тело и язык ещё не разработаны. Физическая жизнь использует временные механизмы F2; старые реплики/память не названы новой личностью. Мир открывается на паузе и не продвигает время тайно после закрытия вкладки. Реальные S24/Xbox не проверены браузерной эмуляцией. Уменьшение активного состава до десяти — заданный старт, не пожизненная квота и не скрытое восстановление населения.
